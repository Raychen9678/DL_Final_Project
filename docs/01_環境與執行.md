## A. Kaggle

### 第一次設定

1. Kaggle → **Settings → Phone verification**（沒驗證不能用 GPU、不能提交）
2. 打開 [比賽頁](https://www.kaggle.com/competitions/isic-2024-challenge) → **Late Submission** → 同意規則

### 匯入 notebook

比賽頁 → **Code → New Notebook → File → Import Notebook** → 選 `notebooks/` 裡的檔案

> 不要用右側的 **Upload**，那會變成資料集，不會放進 notebook。

### 各 notebook 的設定

| Notebook | Accelerator | Internet | 要提交嗎 |
|---|---|---|---|
| `isic2024_baseline.ipynb` | None（CPU） | **關** | ✅ |
| `isic2024_image_models.ipynb` | **GPU** | **開**（下載預訓練權重） | ❌ |
| `isic2024_multimodal.ipynb` | **GPU** | **開** | ❌ |
| `isic2024_submission.ipynb` | **GPU** | **關** | ✅ |

設定位置：notebook 右側面板 **Session options / Settings**。

### 跑自己的實驗

1. 打開 `isic2024_image_models.ipynb`，在「選實驗」那格把 `EXP = 'BASE'` 改成自己的編號（例如 `'B2'`，編號表見 [03_分工與時程](03_分工與時程.md)）
2. **Save Version → Save & Run All**，每個編號存一個版本（約 30–60 分鐘）
3. 跑完：最後一格會印出一行結果，貼到群組；到版本頁 **Output** 下載 `exp_{EXP}.json`，放進專案的 `results/`
4. 全組彙整：`python src/collect_results.py` → `results/summary.md`

> 第一次一定先跑 `BASE`（Round 0 對齊）。

### 提交

1. 打開 `isic2024_submission.ipynb`
2. 右側 **Add Input → Your Work**，加入圖片模型 notebook 的各個版本（會自動偵測）
3. Internet 關 → **Save Version** → 跑完後回比賽頁 **Late Submission** → 選這個 notebook、輸出 `submission.csv` → **Submit**
4. 比賽頁 **Submissions** 分頁看 Public / Private Score（重跑測試集約 10–30 分鐘）

### 常見問題

| 狀況 | 解法 |
|---|---|
| `FileNotFoundError: train-metadata.csv` | 右側 Input 沒加入比賽資料 |
| 提交失敗 | Internet 沒關，或輸出檔名不是 `submission.csv` |
| Output Data 只有 3 筆 | 正常，提交時 Kaggle 會換成真正的測試集 |
| 圖在哪裡 | 每格下面的輸出；也存成 PNG 在 Output 的 `figures/` |

## B. 自己的電腦

```bash
pip install -r requirements.txt
python src/download_data.py         # ISIC 官網下載 metadata（約 90 MB，不用 Kaggle 帳號）
python src/eda.py                   # 資料分析 → reports/
python src/train_lgbm.py            # LightGBM 5 折，約 10 秒
python src/train_mlp.py             # Logistic Regression + MLP，約 30 秒
python src/train_mlp.py --ablation  # 再加優化器、正則化消融實驗，約 4 分鐘
```

- 一律從專案根目錄執行 `python src/xxx.py`
- 要圖片：`python src/download_data.py --kaggle`（約 2.7 GB，需要 Kaggle API token 放在 `C:\Users\<帳號>\.kaggle\kaggle.json`，**不要放進專案**）
- 輸出在 `reports/`、`models/`，不會上傳 GitHub
