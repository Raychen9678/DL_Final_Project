# 01 操作說明（組員照著做就好）

全部在 **Kaggle 網頁**上操作，不用裝任何東西。

---

## 第一次：準備帳號（10 分鐘，只做一次）

1. 註冊／登入 [Kaggle](https://www.kaggle.com)
2. 右上角頭像 → **Settings** → **Phone verification**，完成手機驗證
3. 打開 [比賽頁](https://www.kaggle.com/competitions/isic-2024-challenge) → 按 **Late Submission** → **I Understand and Accept**

---

## 跑實驗（每個實驗都一樣，4 步）

### 1. 下載 notebook

在這個 GitHub 打開 [`notebooks/isic2024_image_models.ipynb`](../notebooks/isic2024_image_models.ipynb) → 右上角 **下載按鈕（Download raw file）**

### 2. 匯入 Kaggle

比賽頁 → **Code** → **New Notebook** → 上方選單 **File → Import Notebook** → 選剛下載的檔案

> ⚠️ 不要用右邊的 **Upload**，那個會變成資料集。

### 3. 設定（右側面板 Session options）

- **Accelerator**：`GPU T4 x2`（或任一 GPU）
- **Internet**：**On**

### 4. 改一行、存檔

找到「選實驗」那格，把

```python
EXP = 'BASE'
```

改成你的編號（**第一次大家都先跑 `BASE`**），然後右上角 **Save Version → Save & Run All → Save**。

不用盯著，關掉網頁也會繼續跑（約 30–60 分鐘）。

---

## 你的實驗編號

| 你是 | 依序跑這些 |
|---|---|
| 所有人 | `BASE`（先跑） |
| A | `A1` → `A2` → `A3` |
| B | `B1` → `B2` → `B3` → `B4` |
| C | `C1` → `C2` → `C3` → `C4` |
| D | `D1` → `D2` → `D3` → `D4` |
| E | 見下方「E 專用」 |

每個編號重複上面第 4 步：改 `EXP` → Save Version。同一個 notebook 存多個版本就好。


---

## E 專用

| 編號 | 怎麼跑 |
|---|---|
| `E1`、`E2` | 已完成（Logistic Regression 0.103、MLP 0.159），不用跑 |
| `E4` 多模態 | 跟上面一樣，但下載的是 [`isic2024_multimodal.ipynb`](../notebooks/isic2024_multimodal.ipynb)，不用改任何東西，直接 Save Version |
| `E3` 融合＋提交 | 下載 [`isic2024_submission.ipynb`](../notebooks/isic2024_submission.ipynb) → 匯入 → 右側 **Add Input → Your Work** 加入你跑 `BASE` 的那個 notebook → **Internet 改 Off** → Save Version → 跑完到比賽頁按 **Late Submission** 選這個 notebook 提交 |

---

## 出問題時

| 看到 | 怎麼辦 |
|---|---|
| `FileNotFoundError ... train-metadata.csv` | 右側 **Input** 沒有比賽資料 → **Add Input** 搜尋 `isic-2024-challenge` |
| 沒有 GPU 選項 | 手機驗證沒完成 |
| `KeyError: 'A5'` 之類 | 編號打錯，對照上面的表 |
| 提交失敗 | 提交用的 notebook 要 **Internet Off** |
| 其他錯誤 | 截圖錯誤訊息貼到群組 |
