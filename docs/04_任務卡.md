**你要回答的問題**：CNN、ResNet、EfficientNet、ViT，哪個最適合這種小病灶圖？為什麼？

| 書面報告 | 4.4、5.1，最後整合全文 |

**口試可能被問**
- **Simple CNN 的每一層在做什麼？** Conv 抽局部特徵（邊緣、顏色塊），BN 穩定訓練，ReLU 非線性，MaxPool 縮小尺寸、保留最強訊號，最後 Global Average Pooling + FC 輸出。
- **為什麼用 ImageNet 預訓練？** 惡性只有 393 張，從零學太少；預訓練模型已經學會邊緣、紋理等通用特徵，只要微調。
- **ResNet 的殘差連接解決什麼？** 網路很深時梯度會消失、效果反而變差；殘差讓每層學「F(x) + x」，梯度可以直接傳回前面。
- **ViT 跟 CNN 差在哪？** ViT 把圖切成 16×16 的 patch，用 self-attention 看全部 patch 的關係；CNN 天生只看局部。ViT 缺少這種「局部性」先驗，通常需要更多資料，小圖、小資料上可能比較吃虧。

## B：優化器與學習率

**你要回答的問題**：SGD、Adam、AdamW 和不同學習率，對收斂速度和最終分數影響多大？

| 項目 | 內容 |
|---|---|
| 要跑 | `BASE` → `B1` SGD+Momentum → `B2` Adam → `B3` lr 1e-3 → `B4` lr 1e-4 |
| 已完成可直接用 | MLP 優化器消融：`figures/05_optimizer_comparison.png`（SGD 0.158 / Adam 0.150 / AdamW 0.154） |
| W12 簡報 | P2 任務與評分頁：檢查內容、練講稿 |
| W14 簡報 | 2 頁：圖片模型的優化器比較＋訓練曲線、MLP 先導實驗 |
| 書面報告 | 4.1、5.2 |

**口試可能被問**
- **pAUC 怎麼算？為什麼不用 accuracy？** 畫 ROC 曲線，只算 TPR ≥ 0.8 那段的面積（0–0.2）。惡性只有 0.1%，全猜良性 accuracy 就 99.9%，沒有意義。
- **Momentum 做什麼？** 累積過去梯度的方向當「速度」，減少震盪、衝過平坦區。
- **Adam 和 SGD 差在哪？** Adam 對每個參數用各自的學習率（用梯度的一階、二階動量調整），所以收斂快。
- **Adam 和 AdamW 差在哪？** AdamW 把 weight decay 從梯度更新裡分開，正則化效果才正確。
- **學習率太大／太小會怎樣？** 太大會震盪甚至發散，太小收斂很慢、可能卡在不好的地方。
- **我們的圖看到什麼？** Adam 類 5–10 epoch 就到最高，之後下滑；SGD 慢但穩 → 需要 early stopping。

## C：正則化與資料增強

| 書面報告 | 4.3、5.3 |

**口試可能被問**
- **資料增強為什麼有用？** 用翻轉、旋轉、調色產生「看起來不同但答案一樣」的圖，等於增加資料、減少死背。
- **為什麼病灶圖可以上下翻、任意旋轉？** 皮膚病灶沒有固定方向，翻過來還是同一顆痣（一般照片就不能上下翻）。
- **Dropout 怎麼運作？** 訓練時隨機關掉一部分神經元，逼網路不依賴特定神經元；推論時全部開啟。
- **為什麼推論要 `model.eval()`？** 讓 Dropout 關閉、BatchNorm 改用訓練時累積的平均與變異數，不然結果會隨 batch 變動。
- **怎麼從曲線看出 overfitting？** train loss 一直下降，但驗證分數到某個 epoch 後開始變差（我們的 MLP 約第 10 epoch）。

## D：不平衡處理

**你要回答的問題**：惡性只有 0.1%，抽樣、加權、Focal loss 哪個最有效？

| 項目 | 內容 |
|---|---|
| 要跑 | `BASE` → `D1` 抽樣 1:5 → `D2` 抽樣 1:50 → `D3` pos_weight → `D4` Focal loss |
| 已完成可直接用 | EDA 圖（類別分布、相關性熱力圖）；LightGBM 加權失敗的例子（0.129 → 0.031） |
| W12 簡報 | P4、P5 資料分析：檢查內容、練講稿 |
| W14 簡報 | 2 頁：四種不平衡處理比較 |
| 書面報告 | 第 3 章（EDA）、5.4 |

**口試可能被問**
- **資料有多不平衡？** 401,059 張只有 393 張惡性（0.098%）。
- **為什麼驗證集要按病人切？** 每人中位數 242 張圖，同一人的痣很像；隨機切會讓模型在驗證時看過這個人，分數虛高。
- **抽樣比例在做什麼？** 每個 epoch 用全部惡性 + 隨機抽惡性 N 倍的良性，讓模型看得到足夠的惡性；每個 epoch 重新抽，比固定抽一次能看到更多不同的良性。
- **pos_weight 做什麼？** 惡性樣本的 loss 乘上權重，算錯惡性罰更重。
- **Focal loss 的直覺？** 乘上 (1 − p)^γ：已經很有把握的樣本 loss 變很小，讓模型專注在難判斷的樣本。
- **為什麼 LightGBM 加權反而變差？** 只有 393 個正樣本，加權後大模型把它們硬背下來，驗證時完全失準。

**口試可能被問**
- **為什麼 Logistic Regression 等於單層感知器？** 沒有隱藏層：輸入 × 權重 + bias → sigmoid，就是感知器加上 sigmoid 輸出機率。
- **MLP 為什麼比它好很多？** 隱藏層 + ReLU 能學非線性組合；EDA 顯示單一特徵跟惡性的相關都 < 0.05，需要組合。
- **病人內標準化是什麼？** 每顆痣的特徵減掉同一人的平均、除以標準差，代表「這顆跟這個人其他痣比有多特別」（醫生的醜小鴨判斷法）。
- **Stacking 是什麼？為什麼用 OOF？** 把圖片模型的預測當成 LightGBM 的新特徵。訓練資料要用 OOF（模型沒看過那筆的預測），不然等於偷看答案。
- **多模態和 Stacking 差在哪？** 多模態是一個網路同時吃圖片和表格、一起反向傳播；Stacking 是兩階段，先各自訓練再組合。
- **為什麼提交要關網路？** Code Competition 規定，Kaggle 會用隱藏測試集重跑你的 notebook，防止外流資料。
