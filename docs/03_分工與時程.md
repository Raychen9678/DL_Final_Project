# 03 分工與時程

## 分工原則

**五個人同時跑完整流程，各自負責一個「實驗變因」**，其他設定一律照「共同基準」，最後放進同一張表互相對照。

- 共用程式、資料讀取、驗證切分、評分都已經寫好 → **沒有人需要等別人**
- 每人用自己的 Kaggle 帳號跑 → GPU 額度各自一份
- 每個實驗只要在 notebook 改一個編號 `EXP = 'B2'`，其餘設定已預先寫好

## 時程（Round 制）

| Round | 期間 | 全組要做的 | 產出 |
|---|---|---|---|
| **Round 0 對齊** | W11 | 每人用自己帳號跑 `BASE` 一次，分數貼群組 | 五個 BASE 分數應該很接近；差很多 = 環境或流程有錯，先修好 |
| **Round 1** | W12–W13 | 跑自己的實驗編號（每個預估 30–60 分鐘 GPU，第一次跑完請回報實際時間） | 每個實驗一份 `exp_XX.json` |
| **Round 2** | W14 | 各自挑出最好的設定；`python src/collect_results.py` 產生全組比較表 | W14 簡報：每人 2 頁（自己的變因） |
| **Round 3 合併** | W15 | 把各變因的最佳設定合併成最終模型（notebook 的 `EXP = 'FINAL'`，做法見 [02 一、專題整體流程](02_模型與實驗.md#一專題整體流程)），E 提交 | 最終 Kaggle 分數、程式定版 |
| 口試 | W15–W16 | 每人講自己的變因：改了什麼、結果、為什麼 | — |
| 書面報告 | W17 | 每人寫自己變因那一節（5.1～5.5），A 整合 | 書面報告 |

**W12 簡報（11/25 前）**：每人負責上表「對應簡報頁」那一頁的內容檢查。
