# 00 專題說明

> 第一次接觸這個專題，先看這份。

## 一句話

給電腦看一張皮膚上痣或斑點的照片，加上病人的基本資料，讓它判斷這顆是不是**皮膚癌**。

這是 Kaggle 比賽 [ISIC 2024](https://www.kaggle.com/competitions/isic-2024-challenge)。目的是在沒有皮膚科醫師的地方，先用 AI 篩出可疑的病灶。

## 資料

- **40 萬張病灶小照片**：從全身 3D 攝影裁下來，每張一百多像素見方，畫質接近手機照片
- **每張照片附一列資料**：年齡、性別、身體部位、病灶大小，以及 30 多個系統算出的顏色、形狀數值
- **答案** `target`：1 = 惡性，0 = 良性

## 難在哪

| 難點 | 說明 | 我們的對策 |
|---|---|---|
| 惡性非常少 | 40 萬張只有 393 張，不到千分之一。全部猜良性，準確率就有 99.9% | 每輪訓練重新抽樣良性；不看 accuracy |
| 同一人有很多張 | 每位病人中位數 242 張，最多 9,184 張 | 驗證集**按病人切**，避免分數虛高 |
| 評分很嚴格 | **pAUC**：只看「抓出至少 80% 癌症」時的表現，範圍 0–0.2，亂猜約 0.02 | 自己實作官方評分，每個模型都用它比較 |

## 整體流程

每一次實驗都是同一條完整流程，程式已經寫好：

```
讀資料 → 建特徵 → 按病人切 5 折 → 訓練（early stopping）→ 算 pAUC → 輸出結果 json
```

我們**不是照流程分工**，而是**每個人都跑完整流程、各自改一個「實驗變因」**：

| 組員 | 變因 | 問的問題 |
|---|---|---|
| A | 模型架構 | CNN、ResNet、EfficientNet、ViT 哪個適合這種小病灶圖？ |
| B | 優化器與學習率 | SGD、Adam、AdamW 收斂和最終表現差多少？ |
| C | 正則化與資料增強 | 增強、Dropout 能不能減少 overfitting？ |
| D | 不平衡處理 | 抽樣、加權、Focal loss，哪個最能處理 0.1% 的惡性？ |
| E | 輸入資料與融合 | 只用表格、只用圖片、兩者融合，差多少？ |

其他設定都照「共同基準」，所以結果可以放在同一張表比較。詳見 [03_分工與時程](03_分工與時程.md)。

## 為什麼要兩種資料、這麼多模型

- **表格**和**圖片**各有擅長的地方，比賽前段隊伍都把兩者結合
- 這門課是深度學習，所以模型選擇對應上課內容（感知器、MLP、CNN、ResNet、Transformer），並用 LightGBM 當對照組，看深度學習做得如何
- 詳細見 [02_模型與實驗](02_模型與實驗.md)
